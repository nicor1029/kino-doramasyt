# doramasyt (plugin de Kino)

Plugin de Kino para ver doramas asiáticos (K-Dramas, C-Dramas, J-Dramas y más) de doramasyt.com, en subtítulos y en latino.

- No pide cuenta ni configuración.
- Permite descargas para ver sin conexión.
- Servidores: MP4Upload, ok.ru, Lulu y Uqload.
- Por ahora solo series, sin películas.

Requiere Kino 0.9.45 o más nuevo. Para instalarlo: Plugins, botón +, escribe `Nicor1029/kino-doramasyt`.
